## Selected work

I don't pad my GitHub with tutorial repos. What's here is shipped code:

- **Offline-first architecture** — Easymony stores all financial data in a local SQLite database. No cloud dependency. No server to breach. Works on a subway with zero connectivity.
- **Custom budget engine** — Two-level category system (Category → Subcategory) with unlimited nesting in Premium. Color-coded, user-defined, zero presets.
- **PDF report generation** — On-device PDF export with custom branding, category filtering, and date ranges. No third-party API.
- **Encrypted backup system** — ZIP-based local backups with optional Google Drive auto-sync. Encryption happens before the file leaves the device.
